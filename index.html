Install v0.2.0-preview

An unsigned Windows x64 installer with a LocalService background service, tray and browser-app dashboard. Preview only: do not use for sensitive activity. Interactive installation/removal, alternate-admin UAC and desktop Chrome routing are not verified.

  1. 1

    Remove the older preview first

    Turn off and remove its Chrome extension. For v0.1.0, run its Uninstall.cmd. For another service preview, uninstall it in Windows Apps. Close Chrome. Saved encrypted profiles are retained for the same Windows user; old program files are not migrated.

  2. 2

    Run Setup from your normal desktop

    Run WireGuard-Companion-Setup-0.2.0-preview-x64.exe from the intended user's interactive desktop. Approve administrator access. Alternate-admin UAC is designed to preserve the desktop user's control identity, but is not yet verified. Headless/session-0 installation fails closed.

    Unsigned preview: do not disable SmartScreen, antivirus or organization policy. If blocked, stop that installation.

  3. 3

    Load the installed Chrome extension

    Open chrome://extensions, turn on Developer mode, choose Load unpacked, and select C:\Program Files\WireGuard Companion\extension.

  4. 4

    Connect in Chrome to enable routing

    Choose Add profile in Chrome, import your WireGuard .conf, select it and Connect. Optional WARP uses unofficial wgcf: read Cloudflare's linked terms and explicitly agree before registration. No live WARP registration has been tested.

  5. 5

    Understand what runs in the background

    The service starts with Windows, but does not reconnect automatically after reboot. Open WireGuard Companion from Start for the tray and local dashboard; the tray is not added to startup. Quitting the tray does not stop an active tunnel.

    Dashboard Connect starts the tunnel, not Chrome's proxy. Enable routing in Chrome. Dashboard Disconnect can leave Chrome blocked until you choose Turn off in the extension. A running service is not a connected tunnel; Connected requires a peer handshake.

To remove: Turn off in Chrome, remove the extension, quit tray, then uninstall in Windows Apps. Saved profiles remain under %APPDATA%\wg-companion\configs. Original imported files remain where you put them.

What it does not do

Plain limits, so you can decide.

Windows checks, not desktop proof

Real Windows CI passed DPAPI, service start/status/stop, pipe-denial and tunnel HTTP/DNS tests. Installer welcome/license screens were inspected. Interactive installation/removal, alternate-admin UAC, tray behavior and non-admin Windows Chrome end-to-end remain unverified.

TCP only

Regular browsing over TCP. No arbitrary UDP or SOCKS5 UDP. QUIC/HTTP3 behavior is not exhaustively verified. Incognito is unsupported.

No guarantees

No leak-proof claim or speed promise. No system-wide kill switch. Endpoint hostname DNS uses your normal network to bootstrap the tunnel. WebRTC, QUIC and IPv6 are not fully packet-verified.

Your peer, your trust

Traffic goes where your config says. Other apps keep their own network path. Any local user can use the loopback SOCKS proxy while it is active. No analytics on this site.

Questions

Do I need administrator rights?

Yes. The v0.2.0 installer requires administrator approval to register the service. Run it from the intended user's normal interactive desktop. Alternate-admin UAC targeting remains unverified.

Is there a Windows installer or background service?

Yes, in v0.2.0-preview. Service tests passed on Windows CI, but the interactive installer/uninstaller and desktop behavior have not been verified. This is unsigned preview software.

Does it work with Edge, Firefox or Brave?

Only Chrome has been built for. Others are untested.

Where is my config stored?

On your machine, in your user profile. The project runs no server that receives it.
