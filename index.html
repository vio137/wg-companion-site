Install the preview

Current preview uses a script installer and an unpacked extension. A proper Windows installer and background service are in development and are not available yet.

  1. 1

    Get the ZIP

    Download WireGuard-Companion-Windows-x64-preview.zip from the release page, then extract it to a folder you will keep.

  2. 2

    Run the companion installer

    Open the extracted folder and run Install.cmd. Follow the README included in the ZIP for the required order and any extension ID registration.

  3. 3

    Load the extension in Chrome

    Open chrome://extensions, turn on Developer mode, choose Load unpacked, and select the extension folder from the ZIP.

  4. 4

    Add your own WireGuard config

    Use a config for a peer you control or trust. Follow the included README to import it and connect. Only a regular Chrome profile is in scope; incognito is not.

Step details follow the README shipped in the ZIP. If something differs, the README is right.

What it does not do

Plain limits, so you can decide.

Not run on Windows yet

Tests so far ran on Linux: real Chromium, a local WireGuard peer, HTTP and DNS through the tunnel, crash blocking and reconnect. The Windows build is cross-compiled only.

TCP only

Regular browsing over TCP. No arbitrary UDP or QUIC, and incognito windows are not routed.

No guarantees

No leak-proof claim and no speed promise. Measure on your own setup.

Your peer, your trust

Traffic goes where your config says. There is no relay run by this project, and no analytics on this site.

Questions

Do I need administrator rights?

Not for the current preview installer, which is per-user. The planned Windows service will need one approval to register.

Is there a Windows installer or background service?

Not yet. Both are under development and will be announced here only after they are built and checked.

Does it work with Edge, Firefox or Brave?

Only Chrome has been built for. Others are untested.

Where is my config stored?

On your machine, in your user profile. The project runs no server that receives it.
